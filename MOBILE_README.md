# Asteroids - Mobile HTML5 Version

A mobile-friendly HTML5 version of the classic Asteroids game, optimized for touch controls and responsive gameplay.

## Features

- **Full HTML5 Canvas Game** - Runs in any modern browser
- **Mobile-Optimized** - Touch controls for mobile devices
- **Responsive Design** - Adapts to any screen size
- **Progressive Difficulty** - Levels get harder as you progress
- **Particle Effects** - Satisfying visual feedback
- **Keyboard Support** - Desktop play with arrow keys and spacebar

## How to Play

### Mobile Controls
- **Left/Right Arrows** - Rotate your ship
- **Up Arrow** - Thrust forward
- **Fire Button** - Shoot asteroids

### Desktop Controls
- **Arrow Keys / WASD** - Rotate and thrust
- **Spacebar** - Fire

## Gameplay

- Destroy asteroids by shooting them
- Larger asteroids split into smaller ones
- Avoid collisions with asteroids
- Each level increases the number of asteroids
- You have 3 lives to start

## Deployment

This game is deployed via GitHub Pages and can be played at:

## Technical Details

- Pure HTML5, CSS3, and JavaScript
- No external dependencies
- Canvas API for rendering
- Touch event handling for mobile
- Requestanimationframe for smooth 60fps gameplay

## Local Development

Simply open `index.html` in any modern web browser to play locally.
